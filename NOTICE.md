# Artwork and icon attribution

Roblox Cinema retains Roblox's own wordmark and native navigation, account, notification, Robux, verification, and status icons on the website. The small SVG set in `src/ui/roblox-icons.json` was captured from the SVG masks rendered by Roblox's official Foundation UI on 22 October 2026. It is used for familiar Roblox destinations inside the extension's isolated sidebar and menu. Roblox names, logos, artwork, and icons belong to Roblox Corporation and their respective owners.

Filled selected-state silhouettes are derived from the captured native SVG contours; they are not an official SF Symbols package.

The verified-badge SVG was captured from Roblox’s native item-details badge on 23 October 2026; its original blue and white colors are retained.

Glass backgrounds use liquid-glass-react 1.1.1 (MIT) with locally bundled React and ReactDOM (MIT). License files are included in `dist/licenses/`.

Remaining interface glyphs use Lucide (ISC license; see the installed `lucide` package). Dependencies are bundled; the extension executes no remote JavaScript.

Apple TV references inform spacing, materials, and motion. No Apple logo, SF Symbols package, generated reference screenshot, or Apple TV artwork is distributed in the extension.

This is an independent customization project and is not affiliated with Roblox or Apple.
